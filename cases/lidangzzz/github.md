## 结构问题（从上表推出，不另起罪名）

1. 星是互动，不是被用出来的。DARC 一键三连换空投是白纸黑字；How-to-run 的星来自转码流量。两项摘掉，他作为开源作者的重量会掉一截。
2. 主页第一行是 Telegram。仓库里塞 Discord / X / YouTube。Issues、Release 不构成社区。
3. Delaware / 转码 / 润加是 gist，用 GitHub 借 star 当权威。
4. OnlySpecs（约 295 star）口号「不要改代码，代码必须从 spec 生成」，可与油管上「程序员判断力不可替代」并排。https://github.com/lidangzzz/OnlySpecs
