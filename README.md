# 福滤娃档案

> 公开言论个案。不是拉黑名单。

本库是 [福滤娃 FeedSieve](https://github.com/realchendahuang/feedsieve) 的姑妹项目：插件负责时间线卫生；档案负责把重复出现的网红话术当教材拆开。

- 主库：https://github.com/realchendahuang/feedsieve
- 档案：https://github.com/realchendahuang/feedsieve-cases

立党（[@lidangzzz](https://x.com/lidangzzz)）是 **卷一**。他进档案，不进福滤娃正式社区黑名单。

## 这不是什么

- 不是攻击名单、不号召拉黑、不开盒、不收集隐私。
- 不是福滤娃扩展的官方 `blocklist.yaml`。
- 观点、立场、兴趣差异不是入档理由。入档只看：公开言论能否被核对、模式是否完整、对时间线气氛有没有教材价值。
